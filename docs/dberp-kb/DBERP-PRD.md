# DBERP 进销存系统 · 产品需求文档（PRD）

> 作为「软件测试工程师求职作品集」中被测系统（SUT）的权威需求基线。
> 版本：V 1.3 Release 250320（Laminas + Doctrine 2）。本文与《DBERP使用文档.md》配套，可共同导入 RAG 知识库。

## 1. 背景

DBERP 是北京珑大钜商科技有限公司开发的面向中小企业的 Web 进销存管理系统。目标是用一套系统管清采购、销售、库存、往来结算与经营数据，业务流程可追溯、数据私有化部署。本 PRD 基于实际部署版本（1.3）梳理功能需求，作为测试设计、用例编写与 AI 测试平台（ai-testflow）的被测对象基线。

## 2. 目标

- **G1 业务闭环**：采购→入库→销售→出库→收付款→报表形成完整链路，减少漏单、错账。
- **G2 库存可视**：多仓、批次、序列号、效期、调拨、盘点、库存流水可追溯。
- **G3 资金清晰**：应收应付、收付款、核销、账龄集中管理。
- **G4 经营洞察**：经营看板与报表提供销售、库存、资金指标。
- **G5 权限可控**：按模块/导航授权，关键操作审计，导出留痕。
- **G6 自主可控**：支持私有化部署与在线更新。

## 3. 功能需求（按模块）

### 3.1 基础资料（主数据）【P0】
- FR-1.1 商品资料：增删改查，含名称/编号/规格/单位/分类/品牌/图片；支持自定义字段。
- FR-1.2 商品分类：多级分类。
- FR-1.3 品牌、单位维护；商品支持多单位换算。
- FR-1.4 序列号：单件商品序列号登记与流转追踪。
- FR-1.5 仓库：多仓库资料。
- FR-1.6 客户/供应商及分类：往来单位统一维护。
- FR-1.7 部门岗位：业务员归属。
- FR-1.8 地区：省市区数据。

### 3.2 采购管理【P0】
- FR-2.1 采购订单：创建/审核/取消审核；选择供应商、付款方式；序列号逐条录入。
- FR-2.2 采购入库：验货完成「等待入库/直接入库」；入库后库存+，生成应付。
- FR-2.3 采购退货：订单审核后、入库前退货；作废退货刷新应付。
- FR-2.4 采购价格日志：历史价沉淀。

### 3.3 销售管理【P0】
- FR-3.1 销售订单：报价/客户价规/信用控制。
- FR-3.2 销售发货（出库）：按单发货，库存-，生成应收。
- FR-3.3 销售退货：退货入库回补库存。
- FR-3.4 销售价格日志。

### 3.4 库存管理【P0】
- FR-4.1 库存余额：按仓库×商品记录数量/成本。
- FR-4.2 其他出入库：领用/报损/外部入库。
- FR-4.3 调拨：仓库间转移。
- FR-4.4 盘点：账实核对。
- FR-4.5 库存预警：超上下限在预警列表提示。

### 3.5 财务管理【P0】
- FR-5.1 应收账款：应收、收款、流水。
- FR-5.2 应付账款：应付、付款、流水。
- FR-5.3 核销/反核销：关联单据，保证资金业务一致。
- FR-5.4 账龄分析、对账单。

### 3.6 报表与分析【P1】
- FR-6.1 采购/销售/库存/资金报表。
- FR-6.2 经营看板：关键指标、趋势、待办。

### 3.7 系统管理【P0】
- FR-7.1 管理员/管理组：模块授权、角色权限。
- FR-7.2 操作日志：关键操作与导出留痕。
- FR-7.3 打印模板：各业务单据打印样式。
- FR-7.4 系统设置：公司、时区、币种、预警值、验证码、编码前缀等。
- FR-7.5 在线更新中心：分步升级（升级前备份）。

### 3.8 商城对接与 API【P2】
- FR-8.1 商城服务：对接 DBShop/DBCart，商品绑定与订单同步。
- FR-8.2 开放 API：第三方系统整合。

### 3.9 插件扩展【P2】
- FR-9.1 插件中心安装官方插件（AI、审批、发票、条码、导出、消息）。

## 4. 非功能需求

- NFR-1 性能：常规单据列表查询响应 < 2s（数据量 10 万级内）。
- NFR-2 安全：后台需登录；按权限控制菜单与操作；敏感操作审计。
- NFR-3 兼容：PHP 7.4–8.2；MySQL 5.6+/MariaDB 10.5+；Nginx/Apache。
- NFR-4 数据：utf8mb4；关键业务需事务一致（库存与账款联动）。
- NFR-5 部署：运行目录 public；可私有化；HTTPS 建议。

## 5. 验收标准（示例）

- AC-1 采购订单审核后库存与应付款正确联动。
- AC-2 销售发货后库存扣减、应收款生成，且账实一致。
- AC-3 序列号商品在全流程（入库/出库/退货/调拨）可追溯。
- AC-4 库存预警在超阈值时正确提示。
- AC-5 无权限账号不可访问受限菜单/操作；导出留痕于操作日志。
- AC-6 核销后应收应付余额正确，账龄准确。

## 6. 版本规划

- 当前：V 1.3 Release 250320（Laminas + Doctrine 2）。
- 官方主线已发布 3.x（Laravel + Filament，新增销售毛利、移动平均成本、系统邮件、本地部署授权等），但架构不兼容，升级需官方确认方式。
- 测试基线以 1.3 实际部署为准。

## 7. 测试要点（供 ai-testflow 用例设计参考）

- 单据状态机：采购订单「新单→审核→取消审核→入库」的状态转换与边界。
- 库存联动：入库/出库/退货/调拨对 `warehouse_goods` 数量的影响，并发一致性。
- 金额守恒：单据行切换单位时按金额守恒转换单价（3.x 修正点，1.x 需验证）。
- 序列号约束：采购数量与录入序列号数量必须匹配。
- 信用控制：超额订单阻断逻辑。
- 权限：管理组授权粒度、无权限提示。
- 数据校验：编码前缀、商品图片宽高、必填项。
- 升级：在线更新前备份、分步执行、异常恢复。
