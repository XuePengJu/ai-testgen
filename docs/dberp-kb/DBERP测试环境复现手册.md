# DBERP 测试环境复现手册（V 1.3）

> 用途：在阿里云或本地复现这套 DBERP 1.3 测试环境，供作品集演示与回归测试。
> 当前环境：阿里云服务器（域名 erp.agentest.vip，IP 见运维记录不写入公开文档；已部署，`/www/wwwroot/dberp/`）。

---

## 1. 环境规格（已核实）

| 项 | 值 |
|---|---|
| 操作系统 | Alibaba Cloud Linux 8（root） |
| Web 服务器 | Nginx（宝塔管理，运行目录 `public`） |
| 应用框架 | Laminas（Zend Framework 3）+ Doctrine 2 ORM |
| PHP | 宝塔可选 7.4 / 8.0 / 8.1 / 8.2（当前站点 8.2） |
| 数据库 | MariaDB 10.5，库名 `dberp`，字符集 utf8mb4 |
| 部署形态 | 私有化，单服务器 |
| 版本 | DBERP V 1.3 Release 250320（DBERP_VERSION_NUMBER=1.325032000） |

---

## 2. 服务器访问

- SSH：`root@<服务器IP>`（IP 与密钥路径见运维记录，不写入公开文档）。
- 宝塔面板：通过阿里云安全组放行的宝塔端口访问（默认 8888，具体以服务器为准）。
- 生产 Web 根目录：`/www/wwwroot/dberp/`，对外访问根指向 `public`。

---

## 3. 部署/复现要点

1. **运行目录**：网站根目录必须指向 `public`，并开启伪静态/重写（Laminas 路由依赖）。
2. **PHP 扩展**：PDO、openssl、fileinfo、intl、curl、gd2；建议 bcmath、mbstring、zip。
3. **可写目录**：`storage/`、`data/` 及缓存目录需写权限（否则安装/更新/日志失败）。
4. **数据库**：先建库（utf8mb4），导入官方 SQL 或走安装向导；配置落在 `data/erpDatabase.php`。
5. **默认后台账号**：`admin / 123456`（**上线/交付前必须修改**，否则任意人可进后台）。注：当前演示实例（erp.agentest.vip）实际账密为 `admin / admin123`（2026-09-24 核实）。
6. **商城服务**：`shop_service=1` 时可对接 DBShop/DBCart；不对接商城可关闭。
7. **编码前缀**：系统设置中可自定义 商品/分类/品牌/仓库/各单据 的编码前缀（测试时注意前缀冲突）。

---

## 4. 本地复现建议（如需本机搭一套）

- 用 Docker 起 `mariadb:10.5` + `php:8.2-fpm` + Nginx，挂载官方安装包到 `/www/wwwroot/dberp`。
- 或直接在阿里云克隆当前实例做测试机（避免污染生产库）。
- 导入生产结构（不含敏感业务数据）：`mysqldump --no-data dberp` 取结构，本地建空库导入，再用演示数据初始化。

---

## 5. 测试账号与数据准备

- 后台：建议保留 admin 仅用于配置；为测试新建「库管/销售/财务」三组（见《权限矩阵》），分别授权跑权限用例。
- 演示数据当前 `company_name=ERP 演示项目`；测试前确认是否重置（见《测试范围与风险》待澄清 3）。
- 必须自建测试基础数据：≥2 仓库、≥5 商品（含序列号商品、多单位商品）、≥2 客户（1 个设信用额度）、≥2 供应商。

---

## 6. 复现风险与坑点

| 风险 | 说明 | 规避 |
|---|---|---|
| 版本错配 | 3.x 需 PHP 8.3+/MySQL 8.0+，本机是 1.3（PHP 8.2/MariaDB 10.5） | 严格按 1.3 环境，勿混用 3.x 安装包 |
| 默认密码 | admin/123456 未改前任何人可入 | 交付前改密，测试用专用组（演示实例已用 admin/admin123） |
| 在线更新握手 | 开「非浏览器禁止访问」会导致更新失败 | 更新时临时关闭，完毕恢复（《使用文档》9.6） |
| 演示数据污染 | 生产演示数据混入测试断言 | 明确测试库，或与生产隔离 |
| 写入权限 | storage/data 无写权导致安装/日志异常 | 部署后 `chown -R` 给 web 用户并赋 755/775 |
| 重写缺失 | 根目录非 public 或重写未开 → 404 | 核对网站根目录与伪静态规则 |
