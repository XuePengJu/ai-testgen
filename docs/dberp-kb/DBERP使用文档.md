## 3. 基础资料与主数据（怎么用）

基础资料是所有业务的前提，先建档再开单。

### 3.1 商品分类
- **菜单路径**：基础数据 → 商品 → 商品分类
- **添加/编辑字段**（官方）：
  - 分类编码：必填，自行填写
  - 分类名称：必填
  - 上级分类：选填，不选则为顶级分类
  - 排序：必填，升序排列
- **批量更新排序**：勾选分类 → 下拉菜单选「更新排序」→ 点「更新」。
- **删除规则**：当前分类**没有下级分类且没有商品**才可删除，否则需先删商品与下级分类。

### 3.2 商品品牌
- **菜单路径**：基础数据 → 商品 → 商品品牌
- **添加/编辑字段**（官方）：品牌编码（非必填）、品牌名称（必填）、排序（必填）。
- **删除规则**：品牌下有商品则不能删除。

### 3.3 计量单位
- **菜单路径**：基础数据 → 商品 → 计量单位
- **添加/编辑字段**（官方）：计量单位（必填）、排序（必填）。
- **删除规则**：单位下有商品则不能删除。支持「主单位 + 辅助单位」换算（商品多单位 `goods_ext_unit`）。

### 3.4 仓库
- **菜单路径**：基础数据 → 商品 → 仓库
- **操作**：仓库列表 / 添加与编辑 / 排序批量更新 / 删除。
- 支持多仓库；库存按「仓库 × 商品」维度记录（`warehouse_goods`）。

### 3.5 商品（核心主数据）
- **菜单路径**：基础数据 → 商品 → 商品列表
- **操作**（官方目录）：商品列表、添加/编辑商品、批量导入商品。
- **商品字段**（基于表 `dberp_goods`）：商品名称、编号、规格、单位、分类、品牌、自定义字段（`goods_custom`）、序列号开关（`goods_serial_number`）。
- 建议：先建分类、品牌、单位、仓库，再录商品；启用序列号的商品需在出入库时逐条录入序列号。

### 3.6 客户与供应商（往来单位）
- **菜单路径**：客户 → 客户 / 客户组 / 供应商 / 供应商分类
- 维护客户、客户分类、供应商、供应商分类；用于销售价规、信用控制、采购往来。
- 供应商删除规则同主数据：有关联单据/商品则不能删。

### 3.7 部门岗位
- **菜单路径**：企业基础（Company）→ 部门岗位
- 用于业务员归属、权限与业绩统计（`position` 表）。

## 4. 采购管理（怎么用）

采购流程官方文档有完整按钮描述，以下内容为**已核实**。

### 4.1 采购订单
- **菜单路径**：采购 → 采购订单 → 采购订单列表 / 添加采购订单
- **状态机**：新提交 → **审核** →（取消审核可改）→ **验货入库**
- **操作**：
  1. 点「添加采购订单」，选供应商、付款方式（应付账款 / 现金付款 / 预付款），添加商品明细（数量、单价）。
  2. 保存后状态为「新提交」，点「**审核**」。审核后单据锁定不可改。
  3. 如需修改，点「**取消审核**」回到可编辑状态。
  4. 货到后点「**验货入库**」，生成采购入库单。
- **序列号商品**：采购数量内需逐条录入序列号。
- **价格沉淀**：历史采购价写入 `purchase_goods_price_log`，供比价参考。

### 4.2 采购入库单
- **菜单路径**：采购 → 采购入库单 → 采购入库单列表 / 详情
- **说明**（官方）：已入库 + 等待入库的采购单都在这里。
- **操作**：
  - 「验货完成、等待入库」的订单，列表中点「**入库**」按钮才正式入库，库存数量 +、生成应付款。
  - 如需退货或其他处理，点「**取消**」按钮。
  - 点「采购入库单详情」查看明细。

### 4.3 采购退货单
- **菜单路径**：采购 → 采购退货单 → 采购退货单列表 / 详情
- **操作**（官方）：
  - 列表支持「**查看**」（退货单详情）、「**退货完成**」（完成退货处理）、「**取消退货**」（取消处理）。
  - 退货会冲减对应应付款、回冲库存。

## 5. 销售管理（怎么用，通用逻辑推导）

> 以下流程基于通用进销存逻辑，请以实际界面核对按钮文案。

### 5.1 销售订单 / 报价
- **菜单路径**：销售 → 销售订单
- **操作**：
  1. 添加销售订单，选客户（触发客户价规与信用控制）、付款方式、商品明细。
  2. 保存后可「审核」。审核后锁定。
  3. 客户价规：系统按客户级别取价；**信用控制**：超出信用额度/账期时阻断下单。

### 5.2 销售发货（出库）
- **菜单路径**：销售 → 销售发货（销售出库单）
- **操作**：
  - 依据已审核销售订单生成发货单，点「出库」后库存自动扣减，生成应收款（`accounts_receivable`）。
  - 序列号商品出库需逐条录入序列号。

### 5.3 销售退货
- **菜单路径**：销售 → 销售退货
- **操作**：
  - 创建退货单，审核后商品「退货入库」（`return_in_warehouse_order`）回补库存，冲减应收款。

## 6. 库存管理（怎么用，通用逻辑推导）

- **菜单路径**：库存

### 6.1 库存余额与流水
- 按「仓库 × 商品」查看数量与成本（`warehouse_goods`）；库存流水记录每次变动。

### 6.2 库存调拨
- **操作**：选源仓库/目标仓库、商品、数量 → 审核/确认 → 源仓减、目标仓加（`stock_transfer`）。

### 6.3 库存盘点
- **操作**：新建盘点单（`stock_check`），录入实盘数量，与账面差异生成盘盈/盘亏，确认后调整库存。

### 6.4 其他出入库
- 其他出库（`other_warehouse_order`）：领用、报损等非销售出库。
- 其他入库（`ex_warehouse_order`）：外部/其他来源入库。

### 6.5 库存预警
- 系统参数 `stock_min_warning` / `stock_max_warning`；低于下限或高于上限的商品在库存预警列表提示。

### 6.6 序列号 / 批次 / 效期
- 启用序列号的商品的序列号在入库、出库、退货、调拨中流转；批次与效期按批次管理（结合序列号表）。

## 7. 财务管理（怎么用，通用逻辑推导）

- **菜单路径**：财务

### 7.1 应收账款
- 销售出库自动生成应收（`accounts_receivable`）；登记收款后核销，流水记 `accounts_receivable_log`。

### 7.2 应付账款
- 采购入库自动生成应付（`finance_payable`）；登记付款后核销，流水记 `finance_payable_log`。

### 7.3 收付款与核销
- 登记收款/付款单，关联业务单据做核销/反核销，保证资金与业务一致；支持对账单、账龄分析。

## 9. 系统管理（怎么用）

### 9.1 系统设置
- **菜单路径**：系统 → 系统设置 → 基本设置 / 发票信息 / 其他设置
- 维护公司名称、时区、币种（CNY）、备案号、发票信息、库存预警值、登录验证码、商品图片宽高、各单据编码前缀等（`system` 表）。

### 9.2 管理员与管理组（权限）
- **菜单路径**：系统 → 管理员 / 管理员组
- **管理员**：列表、添加与编辑、修改密码。
- **管理员组（角色）**（官方）：
  - 系统安装时创建的「**管理员**」组拥有最高权限，**不能删除和修改**。
  - 添加/编辑：填组名（如 库管、销售、运营）+ 「权限设置」勾选不同系统权限（按模块/导航授权）。
- 操作日志（`operlog`）：关键操作与数据导出留痕，可审计、可删除。

### 9.3 地区管理
- **菜单路径**：系统 → 地区管理 → 地区列表 / 添加与编辑 / 删除
- 维护省市区数据（`region`），用于收货/配送地址。

### 9.4 商城绑定（对接 DBShop / DBCart）
- **菜单路径**：系统 → 商城绑定
- DBERP 添加商城、DBShop 商城系统设置、连接商品后同步；其他商城整合 API。

### 9.5 服务绑定（官方）
- **菜单路径**：系统 → 服务绑定
- 重要：服务绑定关联在线更新等官方在线服务，必须先绑定才能用。
  1. **创建账号**：注册珑大会员（https://member.loongdom.cn ，与 DBShop 论坛账号通用）。
  2. **添加网站信息**：填网站名称、网站域名（只填域名）→ 保存生成「标识码」。审核通过前可编辑，审核通过后域名禁止修改。
  3. **服务绑定**：在 DBERP 后台填「珑大会员账号 + 网站标识码」→ 点「绑定」。
  4. **解绑服务**：点「解绑」可重新绑定。

### 9.6 系统更新（官方）
- **菜单路径**：系统 → 系统更新 → 更新列表 / 更新处理
- 完成服务绑定后即可在线更新。
- 注意：更新/插件安装时服务器需做一次网络握手；若启用「非浏览器禁止访问」会导致更新失败，更新时临时关闭，完毕再开启。

### 9.7 打印模板
- **菜单路径**：系统 → 打印模板
- 维护采购单、入库单、销售单、出库单、调拨单、盘点单、收付款单、退货单等单据打印样式（`print_template`）。

## 12. 核心业务流程（标准七步）

1. **建档**：维护商品、客户、供应商、仓库等基础资料。
2. **采购**：创建采购订单 → 审核 → 验货入库（库存+，生成应付）。
3. **销售**：创建销售订单（价规/信用控制）→ 审核 → 发货出库（库存−，生成应收）。
4. **库存**：调拨、盘点、其他出入库维持账实一致。
5. **收付款**：登记收款/付款，核销应收应付。
6. **报表**：汇总采购、销售、库存、往来数据，掌握经营状况。
7. **系统维护**：权限、打印模板、服务绑定、在线更新。

## 15. 部署与运行要求

- 运行目录必须为 `public`（网站根目录指向 public，需开启重写）。
- PHP 扩展：PDO、openssl、fileinfo、intl、curl、gd2；建议 bcmath、mbstring、zip。
- `storage` / `data` 与缓存目录需可写权限。
- 正式环境建议启用 HTTPS。
- 升级前完整备份数据库与项目文件，勿用安装包直接覆盖生产系统。
- 后台默认账号 admin/123456，上线前务必修改（当前演示实例已改为 admin/admin123）。
