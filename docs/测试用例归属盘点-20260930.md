# 测试用例归属盘点（2026-09-30）

背景：ai-testgen 从 ai-testflow 复制后只保留「AI 对话 + 用例生成 + 知识库」域，原项目
ai-testflow 保留探索/自动化/质量/站点域。本盘点覆盖 ai-testflow/tests/ 全部 46 个测试
文件（不含 conftest.py），逐文件按实际 import 内容判断归属。原项目文件零改动。

## 用例数口径

- 全部 46 个文件共 577 个 `def test_` 函数（含类方法）；原项目 584 基线为 pytest 收集
  数（parametrize 展开差额约 +7，散布在 test_auth / test_admin / test_deep_think /
  test_chat_thinking / test_crypto / test_explore_plan）。
- 另有 4 个「脚本式 e2e」文件（test_chat_rag / test_embedding_config /
  test_knowledge_api / test_v41_kb_qa），模块级断言、import 期执行，conftest 中
  `collect_ignore` 显式排除（作者注明用 `python tests/xxx.py` 手动跑），pytest 收集
  0 条，但归属知识库/对话域，随域迁入并保留排除配置。

判域备注：
- test_e2e_conversation.py 虽名带 conversation，实际测 `kind=e2e` 自动化任务的会话
  自动创建/占位回填，属自动化执行链路 → 留原项目。
- test_categories.py 测任务（用例）分类管理 API，属生成域 → 迁入；
  test_category_target.py 测爬取页面的分类同步（TestTarget）→ 留原项目，二者注意区分。
- test_auto_heal / test_auto_runner_partial 顶层 import test_auto_exec 的夹具，与
  test_auto_exec 同属自动化域整体留在 ai-testflow，不存在跨域拆分问题。
- 迁入的 30 个文件无任何对留原地文件的 import 依赖，可整体迁移。
